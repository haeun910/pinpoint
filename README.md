# Pinpoint

채용·청약·청년 지원·공모전 공고 탐색 서비스. Cloudflare Worker에서 공개 목록을 가져오고, 검색·지역 필터·마감일 정렬·관심 공고·월별 캘린더를 제공합니다.

## 실행

Node.js 24 이상. 외부 npm 의존성 없음.

```
npm run build
npm test
node scripts/dev.mjs
```

## 데이터와 수집

`worker/data.js`는 출처와 2026-10-15에 웹 원문 또는 검색에서 확인한 초기 자료입니다. 예시 공고가 아닙니다. 날짜·지원 자격을 확인하지 못한 필드는 명시적으로 원문 확인으로 남겨둡니다. LH 초기 공고는 상세 식별자를 확보하지 못해 공식 목록으로 연결됩니다. 공모전 초기 자료는 검색에서 확인했으며 원문 재확인이 필요합니다.

`/api/notices`는 NAVER Careers, 잡알리오, LH청약플러스, 청년몽땅정보통, 콘테스트코리아 공개 목록을 요청 시 수집합니다. 동일 ID를 중복 제거하고, 성공 응답은 Worker 인스턴스 메모리에 5분 캐시합니다. 마감일이 확인되지 않은 자동 수집 자료는 임의 추정하지 않습니다. 수집 실패 시 초기 확인 자료와 출처별 실패 상태를 반환합니다. 자바스크립트 링크만 제공하거나 봇 차단이 있는 출처는 수집에 실패할 수 있습니다. 개별 공식 API 연동, 인증 키, 전국 모든 기관의 완전 수집, 백그라운드 주기 수집은 아직 제공하지 않습니다.

저장은 기기 내 localStorage를 사용합니다. 로그인·클라우드 동기화·메일 알림은 제공하지 않습니다. 일정이 확인된 공고만 캘린더와 마감 임박 필터에 포함합니다. 한국 시간 기준으로 마감 날짜를 계산하며 당일 마감 시각은 원문을 확인해야 합니다.

## 배포

`.openai/hosting.json`은 Sites 프로젝트를 지정합니다. `npm run build`가 UI를 내장한 Worker ES module을 `dist/server/index.js`에 생성합니다. `dist/.openai/hosting.json`과 함께 tar.gz로 패키징합니다. 배포 전 소스를 Git에 커밋하고 Sites 원격 저장소로 동기화해야 합니다. 인증 토큰은 파일이나 저장소에 기록하지 않습니다.
