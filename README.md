# 핀포인트

청년에게 필요한 공고를 한곳에 모으고, 그중 채용 공고는 지원 준비까지 이어서 할 수 있게 돕는 서비스입니다.

- **채용(메인):** 사기업과 공공기관 공고를 모아 보고, 기업 유형(대기업·중견·중소·스타트업·외국계·공공기관)으로 나눠 봅니다. 공고를 핀하면 마감일에서 거꾸로 계산한 체크리스트와 지원 단계가 생깁니다.
- **청약·주거, 청년 지원, 공모전:** 목록으로 모아 보고 핀해 둘 수 있습니다.
- **공고 붙여넣기:** 사기업 공고는 공개 API가 없어서, 공고 링크나 본문을 붙여넣으면 AI(Claude)가 회사, 마감일, 자격요건, 제출 서류, 자소서 문항을 정리합니다.

## 실행 방법

```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY를 채워 넣으세요
npm run dev                  # http://localhost:3000
```

`ANTHROPIC_API_KEY`가 없어도 화면과 자동 수집은 동작하고, 공고 붙여넣기만 오류 메시지를 보여줍니다. 키는 `.env.local`에만 두고 커밋하지 마세요.

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` | 배포용 빌드 |
| `npm test` | 체크리스트, 수집기, AI 정리 결과 변환 테스트 |
| `npm run typecheck` | 타입 검사 |

## 데이터는 어디서 오나

| 경로 | 대상 | 한계 |
|---|---|---|
| 자동 수집 (`lib/collect.ts`) | NAVER Careers, 잡알리오, LH청약플러스, 청년몽땅정보통, 콘테스트코리아 | 공개 목록 페이지에서 링크와 제목만 가져옵니다. 마감일은 알 수 없어서 "일정 확인"으로 표시하고 지어내지 않습니다. 사이트 구조가 바뀌면 깨질 수 있습니다. |
| 붙여넣기 (`/api/extract`) | 사람인, 잡코리아, 회사 채용 페이지 등 어디든 | 로그인이 필요하거나 스크립트로 그리는 페이지는 링크만으로 열리지 않아서, 본문을 복사해 붙여넣는 게 가장 정확합니다. |
| 예시 공고 (`lib/sample.ts`) | 화면 확인용 | 실제 공고가 아니며 "예시" 표시가 붙습니다. 상단 토글로 숨길 수 있습니다. |

다음 단계로 공공데이터포털 API(공공기관 채용정보, 워크넷, 온통청년, 청약홈)를 붙일 계획입니다.

## 저장

지금은 핀, 체크리스트, 붙여넣은 공고를 브라우저 localStorage에 저장합니다. 로그인과 기기 간 동기화는 Supabase로 옮길 예정입니다.

## 구조

```
app/            Next.js App Router 화면과 API (/api/extract, /api/collect)
components/     보드, 카드, 상세 패널, 공고 추가 창
lib/            타입, 날짜, 체크리스트, 수집기, AI 정리, 예시 데이터
```

## 이전 버전

Cloudflare Worker로 만든 이전 버전(`web/`, `worker/`)은 git 기록에 남아 있습니다. 수집기 로직과 테스트는 이번 버전으로 옮겨 왔습니다.
