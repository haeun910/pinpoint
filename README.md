# Pinpoint

IT/AI 채용·청년 지원·공모전과 분야 제한 없는 청약 공고 탐색 서비스. Cloudflare Worker에서 공개 목록을 가져오고, 검색·지역 필터·마감일 정렬·관심 공고·월별 캘린더를 제공합니다.

## 실행

Node.js 24 이상. 외부 npm 의존성 없음.

```
npm run build
npm test
node scripts/dev.mjs
```

## Codex 자료 수집 및 추천

Codex가 공개 웹 검색·원문 읽기로 확인한 공고를 정리합니다. 공고 확인 → 분류·필터링 → 신입·인턴·입문 교육 중심 추천의 3개 에이전트 역할을 사용합니다. `docs/CODEX_UPDATES.md`에 전체 절차가 있으며 `/api/update-guide`와 MCP `get_notices`로도 읽을 수 있습니다.

`worker/data.js`는 2026-10-15 확인 자료를 초기 화면에 제공합니다. `worker/store.js`는 Codex가 작성한 공고 스냅샷 JSON 파일을 R2에 보관합니다. 일상 자료 갱신은 MCP `upsert_notices` 또는 소유자 전용 Site의 `/api/updates`로 수행하며, 재배포가 필요 없습니다. 사이트 조회·새로고침은 저장된 자료를 읽고 외부 공고 사이트를 직접 수집하지 않습니다. 공고 ID를 유지해 중복 제거하고, revision 충돌과 더 오래된 확인 자료의 덮어쓰기를 거부합니다. 일부 출처를 확인하지 못해도 이전 자료를 삭제하지 않습니다.

제목 및 원문 직무에서 추출한 `roleEvidence`를 기준으로 IT/AI를 분류하며 일반직무의 AI 기업명·태그만으로 통과시키지 않습니다. 출처와 분야 일치, 원문 URL, 날짜, 검증 수준을 쓰기 전에 검증합니다. 청약은 IT/AI 분야 필터 없이 유지합니다. 확인 수준 detail/listing/search를 구분하고, 목록 게시 종료일을 신청 마감으로 추정하지 않습니다.

추천은 `worker/recommend.js`에서 선택한 관심 분야·경력 선호·지역을 기준으로 정렬합니다. 내부 점수를 지원 적합도 백분율로 표시하지 않습니다. 마감 공고는 추천에서 제외하고, 나이·학력·소득·거주 등 확인되지 않은 조건을 함께 안내합니다.

Sites 접근 정책은 본인 전용으로 유지해야 합니다. 서비스 자격은 매 실행 `get_site`에서 획득하고 해당 Site에만 사용합니다. 토큰을 저장소·브라우저 코드·스케줄 프롬프트에 기록하지 않습니다. 공개로 전환할 경우 쓰기 권한을 별도로 설계해야 합니다.

저장은 기기 내 localStorage를 사용합니다. 로그인·클라우드 동기화·메일 알림은 제공하지 않습니다. 일정이 확인된 공고만 캘린더와 마감 임박 필터에 포함합니다. 한국 시간 기준으로 마감 날짜를 계산하며 당일 마감 시각은 원문을 확인해야 합니다.

## 배포

`.openai/hosting.json`은 Sites 프로젝트를 지정합니다. `npm run build`가 UI를 내장한 Worker ES module을 `dist/server/index.js`에 생성합니다. `dist/.openai/hosting.json`과 함께 tar.gz로 패키징합니다. 배포 전 소스를 Git에 커밋하고 Sites 원격 저장소로 동기화해야 합니다. 인증 토큰은 파일이나 저장소에 기록하지 않습니다.
